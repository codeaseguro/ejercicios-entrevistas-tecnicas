## Cómo usar este repositorio

Cada ejercicio sigue el mismo formato:
1. **Planteo del problema** — un caso real reportado, como si llegara a codeaseguro.
2. **Análisis de la problemática** — qué se detecta al revisar arquitectura/código.
3. **Solución propuesta** — el componente o práctica que resuelve el problema, con diagrama.

Pensado para practicar como si fuera una entrevista técnica real, respondiendo antes de mirar la solución propuesta.
